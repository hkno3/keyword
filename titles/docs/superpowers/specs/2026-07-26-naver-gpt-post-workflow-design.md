# 네이버 GPT 포스팅 자동화 설계

## 목적

`D:\keyword\titles`의 미처리 TXT 파일에서 2등 추천 제목을 선택하고, 지정된 웹 GPT 3개로 본문·썸네일·본문 이미지를 생성해 로컬에 저장한다. 최초 검증은 `호카 본디9 와이드.txt` 한 건만 처리한다.

## 입력과 제목 선택

- 테스트 입력: `D:\keyword\titles\호카 본디9 와이드.txt`
- 파일의 `🥈 2등 추천: N번` 표기에서 제목 번호를 읽는다.
- 같은 파일의 `📝 블로그 제목` 목록에서 해당 번호의 제목 전체를 선택한다.
- 테스트 파일의 선택 제목은 `호카 본디9 와이드 신기 전 이것 모르면 5만원 손해`이다.

## 사용하는 웹 GPT

- 글 작성: `https://chatgpt.com/g/g-6a65f293ec488191a1d7c7311fa8eb50-gpt-geul-yoyag-jicim-ai-goji`
- 썸네일: `https://chatgpt.com/g/g-6a65f3acdc6481918c6754754be6b669-gpt-neibeo-sseomneil-garohyeong-jicim`
- 본문 이미지: `https://chatgpt.com/g/g-6a65f6aa226c8191bcf95f6d77e94d20-bonmun-imiji`

## 처리 흐름

1. 테스트 TXT에서 2등 추천 제목을 추출한다.
2. 글 작성 GPT에 선택 제목을 입력하고 응답이 끝날 때까지 기다린다.
3. 글 응답 전체를 본문 텍스트로 저장한다.
4. 썸네일 GPT에 선택 제목을 입력하고 이미지 한 장을 생성한다.
5. 본문에서 아래 세 줄로 구성된 이미지 지시 묶음을 등장 순서대로 추출한다.
   - `[이미지 추천: ...]`
   - `[이미지 삽입 문구: ...]`
   - `[이미지 Alt text: ...]`
6. 각 묶음의 세 줄을 수정·요약하지 않고 그대로 본문 이미지 GPT에 입력해 묶음당 이미지 한 장을 생성한다.
7. 내려받은 썸네일과 본문 이미지를 WebP 형식으로 변환한다.
8. 결과물의 존재와 형식을 검증한다.
9. 모든 검증이 성공한 경우에만 원본 TXT를 `n완료`로 이동한다.

## 결과 저장 구조

결과 폴더:

`D:\keyword\titles\네이버 포스팅\호카 본디9 와이드\`

파일:

- `본문.txt`
- `호카 본디9 와이드 thumbnail.webp`
- `body-01.webp`
- `body-02.webp`
- 이후 본문 이미지 지시 묶음 수에 따라 연속 번호 부여

`body-NN.webp`의 번호는 본문에 이미지 지시 묶음이 나타나는 순서를 따른다.

## 성공 판정과 오류 처리

성공 조건:

- 선택된 제목이 2등 추천 번호와 일치한다.
- `본문.txt`가 비어 있지 않다.
- 썸네일 WebP 파일이 한 장 존재하며 열 수 있다.
- 본문 이미지 지시 묶음 수와 `body-NN.webp` 수가 일치한다.
- 모든 이미지의 실제 형식이 WebP이다.

실패 처리:

- GPT 응답 실패, 이미지 생성 실패, 다운로드 실패 또는 변환 실패 시 원본 TXT를 이동하지 않는다.
- 이미 생성된 결과물은 진단과 재사용을 위해 결과 폴더에 보존한다.
- 재실행 시 기존 파일을 임의로 덮어쓰지 않고, 해당 테스트 실행의 상태를 먼저 확인한다.

## 테스트 범위

이번 단계에서는 `호카 본디9 와이드.txt` 한 건만 처리한다. 결과 품질과 파일 구성이 사용자 검토를 통과한 뒤에만 다중 파일 일괄 처리 또는 폴더 감시 기능을 별도 단계로 설계한다.

## 전제

- 선택되는 브라우저에 ChatGPT 로그인이 되어 있어야 한다.
- 각 GPT의 웹 화면과 생성 기능이 정상적으로 사용 가능해야 한다.
- 네이버 블로그 게시·발행은 범위에 포함하지 않는다.
